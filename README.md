# Global Alcohol Consumption Dashboard

Professional Data Visualization Dashboard built using Streamlit, Pandas, Matplotlib, and Seaborn.

## Features

- Interactive Filters
- KPI Cards
- Multiple Charts
- Dynamic Dashboard
- Dark Professional Theme

## Technologies Used

- Python
- Streamlit
- Pandas
- Matplotlib
- Seaborn

## Run Locally

```bash
py -m streamlit run app.py
